Runtime firmware for YAROC (Yet Another ROC) online orienteering controls running on nRF52840 hardware (e.g. RAK Link.One / WisBlock) using Rust and Embassy. Exposes two USB CDC ACM serial interfaces (telemetry/control packets and device logs) plus a USB DFU Runtime interface for triggering firmware updates.
