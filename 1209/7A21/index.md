USB DFU bootloader for YAROC (Yet Another ROC) nRF52840 online orienteering controls, built with Rust, embassy-boot, and embassy-usb-dfu. Exposes a standalone USB DFU Transfer interface for flashing application firmware updates via dfu-util.
